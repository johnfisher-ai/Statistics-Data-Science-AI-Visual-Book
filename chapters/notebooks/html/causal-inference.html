Causal Inference

An observational loyalty program looks like a big win. We show the confounding hiding underneath, watch the naive difference mislead, then recover the true 120-dollar effect with regression adjustment and propensity-score weighting.

Run top to bottom. Uses pandas, statsmodels, and scikit-learn. The data is simulated with a known true effect (120 dollars) so we can see which estimate is right.

DEMO 1 · Explore first: the naive comparison and its confounding¶

Enrolled customers really do spend more. But look at who enrolled: they already spent more and had been around longer, before the program existed. That imbalance is the confounding that makes the naive difference a lie.

The picture: a causal DAG and the backdoor¶

Before adjusting, draw why the naive number is wrong. In a causal diagram an arrow means 'directly causes'. The confounders prior_spend and tenure_months point into BOTH enrolled and spend, opening a backdoor path enrolled <- prior_spend -> spend that carries non-causal association. Adjusting for the confounders blocks that path, leaving only the causal enrolled -> spend arrow.

import math
from matplotlib.patches import FancyBboxPatch, FancyArrowPatch
FIGW, FIGH, XR, YR = 8.8, 5.2, 10, 7.4
fig, ax = plt.subplots(figsize=(FIGW, FIGH)); ax.set_xlim(0, XR); ax.set_ylim(0, YR); ax.axis("off")

def angle(x0, y0, x1, y1):                        # on-screen slope in degrees (corrects for aspect ratio)
    a = math.degrees(math.atan2((y1-y0)*(FIGH/YR), (x1-x0)*(FIGW/XR)))
    return a + 180 if a < -90 else (a - 180 if a > 90 else a)

def add_node(cx, cy, label, fc, ec, w=2.2, h=1.0):
    p = FancyBboxPatch((cx-w/2, cy-h/2), w, h, boxstyle="round,pad=0.08,rounding_size=0.15",
                       fc=fc, ec=ec, lw=1.8, zorder=3)
    ax.add_patch(p)
    ax.text(cx, cy, label, ha="center", va="center", fontsize=10.5, fontweight="bold", color=ec, zorder=4)
    return (p, (cx, cy))

ps = add_node(3.0, 5.6, "prior_spend",   "#fdf4ff", "#a21caf")   # confounder
tn = add_node(7.0, 5.6, "tenure_months", "#fdf4ff", "#a21caf")   # confounder
tr = add_node(1.8, 2.0, "enrolled\n(treatment)", "#dbeafe", "#2563eb")
ou = add_node(8.2, 2.0, "spend\n(outcome)",      "#dcfce7", "#16a34a")

# patchA/patchB clip each arrow to the node borders, so arrows actually TOUCH the boxes
def edge(a, b, color, lw=2.0, mut=15, z=2):
    ax.add_patch(FancyArrowPatch(a[1], b[1], patchA=a[0], patchB=b[0], shrinkA=1, shrinkB=1,
                 arrowstyle="-|>", mutation_scale=mut, color=color, lw=lw, zorder=z))

for cf in (ps, tn):                              # backdoor arrows: confounder -> BOTH (enter via the top edge)

DEMO 2 · Regression adjustment¶

Put the confounders in the model beside the treatment. The enrolled coefficient is now the effect holding prior spend and tenure fixed, the honest apples-to-apples comparison.

DEMO 3 · Propensity scores and IPW¶

A second route to the answer: model the probability of enrolling from the confounders (the propensity score), then reweight so treated and control groups look alike. The overlap of the two score distributions is what makes adjustment possible at all.

In [5]:
X = df[["prior_spend", "tenure_months"]].values
ps = LogisticRegression(max_iter=1000).fit(X, df.enrolled).predict_proba(X)[:, 1]
df["pscore"] = ps
fig, ax = plt.subplots(figsize=(8, 3.8))
ax.hist(df.loc[df.enrolled==0, "pscore"], bins=30, alpha=0.5, color=BL, label="not enrolled")
ax.hist(df.loc[df.enrolled==1, "pscore"], bins=30, alpha=0.5, color=FU, label="enrolled")
ax.set_xlabel("propensity score  P(enroll | confounders)"); ax.set_title("Propensity overlap between groups"); ax.legend()
plt.tight_layout(); plt.show()

w = np.where(df.enrolled==1, 1/ps, 1/(1-ps))          # inverse-probability weights
ipw = (np.sum(w*df.enrolled*df.spend)/np.sum(w*df.enrolled)
       - np.sum(w*(1-df.enrolled)*df.spend)/np.sum(w*(1-df.enrolled)))
print(f"IPW estimate of the effect = ${ipw:.1f}   (regression ${adj:.0f}, true ${TRUE})")
# balance check: weighted confounder means should move closer together
for col in ["prior_spend", "tenure_months"]:
    t = np.average(df.loc[df.enrolled==1, col], weights=w[df.enrolled==1])
    ctl = np.average(df.loc[df.enrolled==0, col], weights=w[df.enrolled==0])
    print(f"  weighted {col:14s}: enrolled {t:7.1f}  vs  control {ctl:7.1f}")
# the same check in standard deviations, and how much a few large weights matter
t = df.enrolled.values == 1
for col in ["prior_spend", "tenure_months"]:
    x = df[col].values; sd = np.sqrt((x[t].var() + x[~t].var()) / 2)
    before = (x[t].mean() - x[~t].mean()) / sd
    after = (np.average(x[t], weights=w[t]) - np.average(x[~t], weights=w[~t])) / sd
    print(f"  standardized difference in {col:14s}: {before:+.2f} before, {after:+.2f} after weighting")
print(f"largest weight {w.max():.0f}; enrolled customers with a score under 0.05: {(ps[t] < 0.05).sum()}")
rng = np.random.default_rng(0); boot = []
for _ in range(300):                                  # refit the propensity model on each resample
    d = df.sample(len(df), replace=True, random_state=int(rng.integers(1e9)))
    Xd = d[["prior_spend", "tenure_months"]].values; e = d.enrolled.values == 1
    p = LogisticRegression(max_iter=1000).fit(Xd, d.enrolled).predict_proba(Xd)[:, 1]
    wd = np.where(e, 1/p, 1/(1-p))
    boot.append(np.average(d.spend.values[e], weights=wd[e]) - np.average(d.spend.values[~e], weights=wd[~e]))
lo, hi = np.percentile(boot, [2.5, 97.5])
print(f"IPW bootstrap 95% interval: ${lo:.0f} to ${hi:.0f}   (regression's CI: ${ci[0]:.0f} to ${ci[1]:.0f})")

DEMO 4 · Four numbers, one picture¶

The naive estimate stands alone and wrong. Regression lands near the true 120 dollars. IPW lands lower, at about 101, and its bootstrap interval is wide enough to reach 120, because a handful of enrolled customers with tiny propensity scores carry very large weights and prior spend is still not balanced after weighting. The gap between the red bar and the rest is the confounding bias, and the gap between the two adjusted bars is a reminder to check balance and weights before trusting IPW.

Wrap-up¶

The naive +196 dollars was not noisy, it was systematically wrong, because enrollees were bigger spenders before the program. Blocking the backdoor brought regression to +117 dollars, close to the true +120 dollars. IPW (+101 dollars) removed most of the bias but leaned on a few extreme weights, so its estimate is far less precise. Same discipline every time: draw the confounders, adjust for them, and state the no-unmeasured-confounders assumption you are leaning on. Next in Part XXIV: Survival Analysis.
