Forecast Accuracy¶

You have built many forecasts; now grade them fairly. This chapter defines the error metrics, ME, MAE, MSE, RMSE, MAPE, sMAPE, MASE, and Theil's U, shows how they disagree on purpose, and compares two models with the Diebold-Mariano test. Underneath it all, a metric is a loss function, so the “best” model depends on which errors cost you the most.

DEMO 1 · THE ERROR & BIAS (ME)
Start with the residual
Mean Error reveals systematic bias.

resid = {c: a - df[c].values for c in ['model_a','model_b','naive']}
for c,r in resid.items(): print('%-8s  ME (mean error) = %+7.1f' % (c, r.mean()))
fig,ax=plt.subplots(figsize=(10,3.6))
for c,col in zip(resid,[EM,PUR,GREY]): ax.plot(df.index, resid[c], 'o-', color=col, ms=3, label=c)
ax.axhline(0,color='k'); ax.set(title='Residuals (actual - forecast): above 0 = under-forecast', ylabel='error'); ax.legend(); plt.tight_layout(); plt.show()

model_a   ME (mean error) =   +83.8
model_b   ME (mean error) =  +496.0
naive     ME (mean error) =  +827.2

The residual is actual - forecast. The Mean Error (ME) averages them, so it measures bias, the direction of the errors rather than their size. model_a's ME is near zero (errors cancel), but model_b (+496) and naive (+827) sit well above zero, so they systematically under-forecast. A near-zero ME can still hide big errors that cancel, and ME alone is never enough, because it only catches a lean.

DEMO 2 · SCALE-DEPENDENT METRICS
MAE, MSE, and RMSE
How you punish large errors changes the ranking.

def mae(r): return np.abs(r).mean()
def rmse(r): return np.sqrt((r**2).mean())

By MAE: model_a wins (218).  By RMSE: model_b EDGES model_a (532 vs 564)!
why: model_a's single missed spike is squared by RMSE, so one big miss dominates.

These metrics use the error's own units. MAE (mean absolute error) treats every miss equally. MSE and its square root RMSE square the errors first, so a single large miss weighs far more. That is why the ranking flips, with model_a winning on MAE (218 vs 496) while its one missed spike inflates its RMSE above model_b's (564 vs 532). RMSE is always at least MAE, and the gap grows with the spread of the errors. Choosing between them is really choosing how much a big miss should hurt.

DEMO 3 · PERCENTAGE, SCALED & RELATIVE
MAPE, sMAPE, MASE and Theil's U
Scale-free scores you can compare across series.
In [6]:
naive_mae = mae(resid['naive']); naive_rmse = rmse(resid['naive'])
def mape(f): r=a-f; return np.mean(np.abs(r/a))*100
def smape(f): r=a-f; return np.mean(2*np.abs(r)/(np.abs(a)+np.abs(f)))*100
rows=[]
for c in ['model_a','model_b','naive']:
    f=df[c].values; r=resid[c]
    rows.append({'model':c,'MAPE_%':round(mape(f),2),'sMAPE_%':round(smape(f),2),'MASE':round(mae(r)/naive_mae,2),'Theil_U':round(rmse(r)/naive_rmse,2)})
print(pd.DataFrame(rows).to_string(index=False))
print('\nMASE-style relative MAE / Theil U below 1 => beats the seasonal-naive benchmark. Both models do; naive is 1.00 by construction.')

  model  MAPE_%  sMAPE_%  MASE  Theil_U
model_a    2.85     3.04  0.26     0.56
model_b    7.16     7.46  0.60     0.53
  naive   11.73    12.71  1.00     1.00

MASE-style relative MAE / Theil U below 1 => beats the seasonal-naive benchmark. Both models do; naive is 1.00 by construction.

To compare across products or scales you need unit-free scores. MAPE averages the percentage error, intuitive, but it blows up near zero and punishes over- and under-forecasts asymmetrically; sMAPE bounds the over-forecast penalty but is still asymmetric and explodes when actual and forecast are both near zero. MASE and Theil's U are relative to the naive benchmark. Strictly, MASE scales by the naive forecast's MAE on the training data. With only the holdout here we scale by the seasonal-naive forecast's MAE on the same 24 months, a relative MAE, so naive scores exactly 1. Below 1 means you beat naive, and above 1 means you did worse than doing nothing. Both models clear the bar (MASE 0.26 and 0.60), which is the first thing any forecast must prove.

DEMO 4 · COMPARING MODELS
Is A really better than B?
The Diebold-Mariano test, and residual checks.
In [7]:
def dm_test(a, f1, f2, h=1):
    d=(a-f1)**2 - (a-f2)**2; n=len(d); dbar=d.mean(); var=np.mean((d-dbar)**2)
    for k in range(1,h): var += 2*(1-k/h)*np.mean((d[k:]-dbar)*(d[:-k]-dbar))
    stat=dbar/np.sqrt(var/n); return stat, 2*(1-stats.norm.cdf(abs(stat)))
s,p = dm_test(a, df['model_a'].values, df['model_b'].values)
print('Diebold-Mariano  A vs B (squared-error loss): stat %.2f, p = %.3f' % (s,p))
print('p > 0.05 -> the RMSE gap between A and B is NOT statistically significant (driven by one spike).')
lb = acorr_ljungbox(resid['model_a'], lags=[6])['lb_pvalue'].iloc[0]
print('\nmodel_a residual Ljung-Box p = %.2f -> %s' % (lb, 'no evidence of leftover autocorrelation' if lb>0.05 else 'structure remains'))

Diebold-Mariano  A vs B (squared-error loss): stat 0.13, p = 0.897
p > 0.05 -> the RMSE gap between A and B is NOT statistically significant (driven by one spike).

model_a residual Ljung-Box p = 0.99 -> no evidence of leftover autocorrelation

A ranking is only as good as its reliability. The Diebold-Mariano test asks whether two forecasts' errors differ significantly. Here A vs B gives p about 0.90, so the RMSE gap is not statistically distinguishable. It hangs on that one spike, and you should not crown B on RMSE alone. Good practice also checks the residuals, and model_a's show no evidence of leftover autocorrelation in a Ljung-Box test (p about 0.99 on 24 months). That is not proof of white noise, because the test covers only autocorrelation, and the missed promotion spike is itself signal the model did not use.

Reading the verdict from one panel
Read the metric that matches your cost.

There is no single “accuracy” number. On typical accuracy (MAE, MAPE) model_a is the clear winner; if a single large miss is what hurts (RMSE), A and B cannot be told apart on these 24 months. The right call follows the cost of your errors. Report several metrics, check they agree, test the difference, and pick the metric that mirrors the decision.

The accuracy toolkit in one view¶

  1. ME measures bias (a systematic lean) and says nothing about accuracy, since a near-zero ME can still hide canceling errors.
  2. MAE / MSE / RMSE are scale-dependent; RMSE punishes big misses hardest (RMSE always at least MAE).
  3. MAPE / sMAPE are percentage errors, comparable across scales but fragile near zero.
  4. MASE / Theil's U score you against the naive benchmark (here as relative MAE and RMSE on the holdout), and below 1 is the bar every forecast must clear.
  5. Diebold-Mariano tests whether one model is significantly better, because a ranking gap can be noise.

The idea to keep is that a forecast metric is a loss function in disguise. Choosing a metric is choosing which errors you refuse to tolerate, and the honest report shows several, confirms they agree, and tests the difference.
