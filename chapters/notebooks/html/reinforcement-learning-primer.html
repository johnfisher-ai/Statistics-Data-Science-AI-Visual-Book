How reinforcement learning learns from consequences¶

Supervised learning needs labeled answers, and unsupervised learning finds structure. Reinforcement learning needs neither. An agent learns by acting in an environment and collecting rewards, discovering good behavior through trial and error. This notebook builds a tiny GridWorld from scratch, teaches an agent to solve it with Q-learning, visualizes the policy and value function it learns, then uses a multi-armed bandit on realistic ad data written for the book to make the exploration vs exploitation trade-off concrete. Pure numpy, so every moving part is visible.

DEMO 1 · THE ENVIRONMENT
A world with states, actions and rewards
Build a 5x5 GridWorld the agent must navigate.
In [3]:
GRID = 5
start, goal, trap = (0,0), (4,4), (2,2)
walls = {(1,3),(2,3),(3,1)}
MOVES = {0:(-1,0), 1:(0,1), 2:(1,0), 3:(0,-1)}   # up, right, down, left
def step(rc, a):
    r,c = rc; dr,dc = MOVES[a]; nr,nc = r+dr, c+dc
    if nr<0 or nr>=GRID or nc<0 or nc>=GRID or (nr,nc) in walls: nr,nc = r,c   # blocked: stay put
    if (nr,nc)==goal: return (nr,nc), 10.0, True     # reach goal: big reward, episode ends
    if (nr,nc)==trap: return (nr,nc), -10.0, True    # fall in trap: big penalty, episode ends
    return (nr,nc), -0.1, False                       # every step costs a little (encourages short paths)
grid_img = np.zeros((GRID,GRID))
for w in walls: grid_img[w] = -0.5
grid_img[goal] = 1; grid_img[trap] = -1
fig, ax = plt.subplots(figsize=(5,5))
ax.imshow(grid_img, cmap='RdYlGn', vmin=-1, vmax=1)
ax.text(start[1],start[0],'S',ha='center',va='center',fontweight='bold',fontsize=13)
ax.text(goal[1],goal[0],'GOAL',ha='center',va='center',fontweight='bold',fontsize=9)
ax.text(trap[1],trap[0],'TRAP',ha='center',va='center',fontweight='bold',fontsize=9,color='white')
for w in walls: ax.text(w[1],w[0],'#',ha='center',va='center',fontsize=14,color='#334155')
ax.set(title='GridWorld: start (S), reach GOAL (+10), avoid TRAP (-10)', xticks=range(5), yticks=range(5)); plt.tight_layout(); plt.show()

The RL vocabulary in concrete terms. The agent occupies a cell (its state). It picks one of four actions (move up/right/down/left), and the environment returns the next state and a reward: +10 for reaching the goal, -10 for the trap, and -0.1 for every ordinary step (a gentle nudge toward short paths). One run from start to a terminal cell is an episode. Walls (#) block movement. Nobody tells the agent the right moves, so it must discover them from rewards alone.

DEMO 2 · RANDOM vs LEARNED
From trial and error to Q-learning
A random agent flails; Q-learning improves episode by episode.
In [4]:
def run_episode(policy, max_steps=100):
    s = start; total = 0.0
    for _ in range(max_steps):
        a = policy(s); s, r, done = step(s, a); total += r
        if done: break
    return total
random_scores = [run_episode(lambda s: rng.integers(4)) for _ in range(200)]
print('random agent: average return = %.2f' % np.mean(random_scores))
# ---- Q-learning ----
Q = np.zeros((GRID, GRID, 4)); alpha, gamma, eps = 0.1, 0.95, 0.1
curve = []
for ep in range(600):
    s = start; total = 0.0
    for _ in range(100):
        a = rng.integers(4) if rng.random() < eps else int(np.argmax(Q[s[0],s[1]]))
        s2, r, done = step(s, a); total += r
        best_next = 0.0 if done else np.max(Q[s2[0],s2[1]])
        Q[s[0],s[1],a] += alpha * (r + gamma*best_next - Q[s[0],s[1],a])   # the Q-learning update
        s = s2
        if done: break
    curve.append(total)
fig, ax = plt.subplots(figsize=(8,4.2))
roll = pd.Series(curve).rolling(20).mean()
ax.plot(curve, color=LIGHT, lw=0.8, label='per episode'); ax.plot(roll, color=EM, lw=2.4, label='20-episode average')
ax.axhline(np.mean(random_scores), color=RED, ls='--', label='random agent')
ax.set(xlabel='training episode', ylabel='total reward (return)', title='Q-learning: the agent learns to solve the maze'); ax.legend()
plt.tight_layout(); plt.show()
greedy = lambda s: int(np.argmax(Q[s[0],s[1]]))
print('trained agent: average return = %.2f' % np.mean([run_episode(greedy) for _ in range(200)]))

random agent: average return = -10.28

trained agent: average return = 9.30

The update rule. The agent keeps a Q-table, an estimate Q(state, action) of the total future reward for taking that action then acting well after. Each step nudges it toward reality with the Q-learning update: move Q(s,a) a little toward reward + gamma * best next Q. The discount gamma (0.95) makes near rewards count more than distant ones. A random agent averages a badly negative return (it wanders into the trap); after a few hundred episodes the learned agent reliably reaches the goal with a strongly positive return, having been told nothing, only rewarded.

value at start = 6.38 (positive: the agent expects to win from here)

Two views of the solution. The value function V(s) grades each cell by the best return achievable from it. Notice how value rises toward the goal along the route the agent uses, and stays near zero in the lower-left cells it rarely visited, where the estimates have barely moved. The policy is the agent's rule of behavior, which in every cell is to take the highest-Q action. Drawn as arrows, it forms a clear flow from the start that steers around the trap and walls to the goal. Off that route a few arrows are not yet the best move, because Q-learning only converges when every state-action pair keeps being tried and the learning rate shrinks, and 600 episodes with 10% exploration leave some cells under-explored. Value answers 'how good is this state?'; policy answers 'what should I do here?', and Q-learning produced both from raw experience.

DEMO 4 · EXPLORATION vs EXPLOITATION
The central dilemma on teaching ad data
A bandit must balance trying new options against milking the best known one.
In [6]:
try: ads = pd.read_excel('../../data/reinforcement-learning-primer--bandit.xlsx', sheet_name='Data')
except FileNotFoundError: ads = pd.read_excel(BASE + 'reinforcement-learning-primer--bandit.xlsx', sheet_name='Data')
ctr = ads['true_ctr'].values; K = len(ctr); best = int(np.argmax(ctr)); T = 4000
def bandit(strategy, c=0.3):   # UCB's exploration constant, scaled to click rates near 0.1
    Q = np.zeros(K); N = np.zeros(K); opt = []
    for t in range(1, T+1):
        if strategy=='greedy': a = int(np.argmax(Q))
        elif strategy=='eps': a = rng.integers(K) if rng.random()<0.1 else int(np.argmax(Q))
        else: a = int(np.argmax(Q + c*np.sqrt(np.log(t)/(N+1e-9))))   # UCB
        reward = 1.0 if rng.random() < ctr[a] else 0.0
        N[a]+=1; Q[a]+= (reward-Q[a])/N[a]
        opt.append(N[best]/t)
    return np.array(opt), Q, N
fig, ax = plt.subplots(figsize=(8.4,4.6))
for strat,col,lab in [('greedy',RED,'pure greedy (no exploration)'),('eps',EM,'epsilon-greedy (10%)'),('ucb',GREEN,'UCB')]:
    opt,_,Nst = bandit(strat); ax.plot(opt, color=col, lw=2.2, label=lab)
    print(f'{lab}: {opt[-1]:.0%} of visitors saw the best ad by the end, visits per ad {Nst.astype(int).tolist()}')
ax.set(xlabel='visitors served', ylabel='fraction shown the BEST ad', title='Learning which ad wins: exploration pays off'); ax.legend(); ax.set_ylim(0,1)
plt.tight_layout(); plt.show()
opt, Qhat, Nhat = bandit('eps')
print('best ad is %s (true CTR %.1f%%)' % (ads['ad_id'][best], ctr[best]*100))
print('epsilon-greedy sent %.0f%% of traffic to it and estimated its CTR at %.1f%%' % (Nhat[best]/T*100, Qhat[best]*100))

Explore, or exploit? An agent that only exploits (pure greedy) starts with every estimate at zero, so it shows the first ad, and because it never tries the others it never gathers the evidence that AD2 is better. An agent that explores occasionally tries other ads, paying a small short-term cost to find the truly best one. Epsilon-greedy explores at random 10% of the time; UCB favors options it is uncertain about, with a constant that sets how strongly. At the textbook value of 2 it keeps exploring far too long for click rates this small, so the demo uses 0.3. Both then concentrate traffic on the real winner (AD2). This exploration-exploitation balance sits at the center of reinforcement learning, and of A/B testing, recommendation, and clinical-trial design.

Reinforcement learning in one view¶

  • Agent, environment, state, action, reward: the agent acts, the environment responds with a reward and a new state.
  • The goal is to maximize cumulative discounted reward (return), with no label to match.
  • Q-learning learns an action-value table via one update rule; the greedy policy and the value function fall out of it.
  • Exploration vs exploitation is the core dilemma, because you must try new actions to learn, yet exploit what you know to win.
  • RL is the third paradigm, with no labels (supervised) and no fixed dataset (unsupervised), only learning from consequences.
